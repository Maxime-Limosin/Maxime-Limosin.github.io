01 Profile & Background
Embedded Software Engineer

MAXIME LIMOSIN

My journey into programming started in 2017, tinkering with C++ on Arduino and writing BASIC scripts on a Casio Graph 35+ calculator. What began as fascination quickly turned into a dedicated career path.

After building a broad foundation in Computer Science (C, OOP in Java/C++/C#, Web, Linux systems, networking, and databases), I earned my Engineering Degree in Embedded Systems at UTT (France). Since then, I’ve been designing cross-platform desktop applications (Linux/Windows) and real-time software embedded in UAVs.

An RC model aircraft enthusiast and lifelong tech learner, I enjoy exploring new domains, solving low-level challenges, and building clean, reliable software architectures.
